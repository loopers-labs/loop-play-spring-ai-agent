# 2단계 — [정책 인용 규칙] 제거 시 환각 관찰

AssistantPrompt에서 [정책 인용 규칙] 섹션을 일시 제거한 상태. splitter는 800 복원.

## 규칙 제거 상태 — 도메인 밖 질문 '오늘 점심 뭐 먹을까요?'
```
안녕하세요. 오늘 점심 메뉴를 추천해 드리겠습니다. 하지만 먼저 주문하신 음식을 확인해야 합니다. 주문번호를 알려주시면 주문 내용과 금액을 조회할 수 있습니다. 주문번호는 예를 들어 "2024-1234"와 같은 형식입니다.
```

## 규칙 제거 상태 — '비 오는 날 배달이 늦으면 보상 받을 수 있나요?'
```
해당 정보로는 비 오는 날 배달이 늦어졌을 때 보상을 받는 기준을 설명하고 있지만, 구체적인 주문 번호를 통해 확인할 수 있는 보상 여부는 알려드릴 수 없습니다. 주문하신 음식의 배송 상태와 관련된 정보를 제공해주시면 도움이 될 것 같습니다. 주문번호를 알려주실 수 있으신가요?
```
