# 1단계 raw — 인덱싱 시드와 중복 적재 방지

기동 환경: Docker `pgvector/pgvector:pg16` (baedal-pgvector), Ollama `qwen2.5` + `qwen3-embedding:0.6b`, 기본 프로파일(InMemory ChatMemory + PgVector RAG).

## 최초 기동 — 신규 7건 적재

```
[KnowledgeLoader] 적재 완료 — id=privacy / 청크=1개 / 카테고리=account
[KnowledgeLoader] 적재 완료 — id=cancel-policy / 청크=1개 / 카테고리=cancel
[KnowledgeLoader] 적재 완료 — id=coupon-faq / 청크=1개 / 카테고리=coupon
[KnowledgeLoader] 적재 완료 — id=delay-compensation / 청크=1개 / 카테고리=delivery-delay
[KnowledgeLoader] 적재 완료 — id=weather-delay / 청크=1개 / 카테고리=delivery-delay
[KnowledgeLoader] 적재 완료 — id=refund-after-delivered / 청크=1개 / 카테고리=refund
[KnowledgeLoader] 적재 완료 — id=refund-basic / 청크=1개 / 카테고리=refund
[KnowledgeLoader] RAG 시드 완료 — 신규 7건 / 스킵 0건 / 총 7건
```

문서 7건이 모두 `청크=1개`로 적재됐다. 정책 본문이 800 토큰 안에 들어가 `TokenTextSplitter`가 분할하지 않았다는 뜻이다.

## vector_store 적재 현황

```
SELECT count(*) FROM vector_store;
 count
-------
     7

SELECT metadata->>'category', count(*) FROM vector_store GROUP BY 1 ORDER BY 1;
   category     | count
----------------+-------
 account        |     1
 cancel         |     1
 coupon         |     1
 delivery-delay |     2
 refund         |     2
```

## 재기동 — 스킵 7건 (중복 방지)

같은 컨테이너(볼륨 유지) 위에서 앱만 내렸다 다시 띄웠다.

```
[KnowledgeLoader] 이미 적재됨 — id=privacy (개인정보 및 계정 정책)
[KnowledgeLoader] 이미 적재됨 — id=cancel-policy (주문 취소 정책)
[KnowledgeLoader] 이미 적재됨 — id=coupon-faq (쿠폰 사용 FAQ)
[KnowledgeLoader] 이미 적재됨 — id=delay-compensation (배달 지연 보상 기준)
[KnowledgeLoader] 이미 적재됨 — id=weather-delay (기상 악화 시 배달 지연 안내)
[KnowledgeLoader] 이미 적재됨 — id=refund-after-delivered (배달 완료 후 환불 정책)
[KnowledgeLoader] 이미 적재됨 — id=refund-basic (환불 기본 정책)
[KnowledgeLoader] RAG 시드 완료 — 신규 0건 / 스킵 7건 / 총 7건

-- 재기동 후 다시 센 row 수
SELECT count(*) FROM vector_store;  ->  7
```

`alreadyLoaded(faqId)`가 `filterExpression("faqId == '...'")`로 한 건이라도 있으면 스킵하므로, row가 14로 두 배 쌓이지 않고 7로 유지됐다.
