# 3단계 raw — HandoffDetector 상담원 전환

체인 진입 전 컨트롤러에서 `handoffDetector.detect(message)`를 먼저 돌린다.
전환이면 LLM을 부르지 않고 연결 안내(`/assistant`는 String, `/support`는 SupportResponse 수동 조립)를 돌려준다.

## 전환 3종 + support 조립

### S1. EXPLICIT — "상담원이랑 직접 얘기하고 싶어요" (/assistant)
```
상담원 연결을 도와드리겠습니다. 연결이 지연되면 고객센터 1600-0987로 전화 주세요.
[http=200 t=0.048133s]
```

### S2. LEGAL — "이거 너무 화나서 소비자원에 신고할 거예요" (/assistant)
분노("화나서")와 법적("소비자원/신고")이 섞였지만 LEGAL이 ANGER보다 우선이라 LEGAL_ISSUE로 잡혔다.
```
관련 사안은 전문 상담원이 직접 안내드리겠습니다. 고객센터 1600-0987로 연결해 드리겠습니다.
[http=200 t=0.001760s]
```

### S3. ANGER — "나 너무 화나는데 답답해 죽겠네" (/assistant)
```
불편을 드려 죄송합니다. 상담원이 직접 도와드리겠습니다. 고객센터 1600-0987로 연결됩니다.
[http=200 t=0.001477s]
```

### S2'. LEGAL — 같은 입력을 /support로 (SupportResponse 수동 조립)
```json
{"summary":"관련 사안은 전문 상담원이 직접 안내드리겠습니다. 고객센터 1600-0987로 연결해 드리겠습니다.",
 "category":"ETC","urgency":"HIGH","nextAction":"상담원 연결 진행","neededInfo":[],
 "estimatedResolutionMinutes":null,"confidenceLevel":"HIGH"}
[http=200 t=0.004654s]
```

## 서버 로그 — 전환 4건 모두 LLM 호출 없음

```
[Handoff] trigger=EXPLICIT_REQUEST — LLM 호출 없음
[Handoff] trigger=LEGAL_ISSUE — LLM 호출 없음
[Handoff] trigger=HIGH_EMOTION — LLM 호출 없음
[Handoff] trigger=LEGAL_ISSUE — LLM 호출 없음 (support)
```
이 4건 동안 `LLM call` 누적 = **0건**.

## 정량 비교표 (전환 vs 일반 상담)

| 시나리오 | 트리거 | 응답 시간 | LLM 호출 | 연결번호 | 비고 |
| --- | --- | --- | --- | --- | --- |
| S1 상담원 직접 요청 | EXPLICIT_REQUEST | 48ms | 안 함 | 포함 | /assistant String |
| S2 소비자원 신고 | LEGAL_ISSUE | 1.76ms | 안 함 | 포함 | 분노보다 법적 우선 |
| S3 화남·답답 | HIGH_EMOTION | 1.48ms | 안 함 | 포함 | /assistant String |
| S2' 소비자원 신고 | LEGAL_ISSUE | 4.65ms | 안 함 | 포함 | /support ETC·HIGH 조립 |
| 일반 상담 "환불 규칙?" | (전환 아님) | 7890ms | 함 | — | promptTokens=1733 |

전환은 1~48ms에 토큰 0, 일반 상담은 7.9초에 1733토큰. 두 자릿수 ms vs 초 단위의 차이가 분명하다.

## 규칙 우회 — 미탐지 사례 (전부 LLM으로 흘러감)

| 입력 | 의도 | 탐지? | 실제 동작 |
| --- | --- | --- | --- |
| "상 담 원 연결" | 띄어쓰기 우회 | 미탐지 | LLM 호출(7781ms), 주문번호 되물음 |
| "진짜 너무너무 불편했습니다…" | 완곡한 분노 | 미탐지 | LLM 호출(1694ms), "불편하셨다니 안타깝습니다" |
| "agent plz" | 영문 비정형 | 미탐지 | LLM 호출(2041ms), 주문번호 되물음 |

특히 두 번째가 뼈아프다.
정말 화가 났지만 "불편했습니다"라고 점잖게 쓴 고객은 ANGER 패턴(화나/짜증/답답해 죽)에 안 걸려 상담원으로 못 넘어가고, 모델이 주문번호만 되물었다.
규칙 기반 분노 탐지가 "정중한 분노"를 놓친다는 게 응답으로 찍혔다.
(단위 테스트로도 3건 미탐지를 고정해 뒀다.)
